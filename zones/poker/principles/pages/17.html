Buy-In & Stack Size

Buy-In

Initial 'Buy-In' = 20 - 200 of 'Big Blind'
e.g.:

IF
  ( 'Blinds' = $0.25 / $0.50 )
THEN
  Minimum 'Buy-In' (20 bb) = 20 x $0.50 = $10
  Maximum 'Buy-In' (200 bb) = 200 x $0.50 = $100
ENDIF

Stack Size

Short-stacked <= 25 bb
Medium-stacked26 – 50 bb
Big-stacked 51 – 100 bb
Deep-stacked >= 101 bb
