# Buy-In & Stack Size

## Buy-In

[!
Initial 'Buy-In' = 20 - 200 of 'Big Blind'
!]

e.g.:

if
&ensp;( 'Blinds' = &dollar;0.25 / &dollar;0.50 )
then
&ensp;Minimum 'Buy-In' (20 bb)  = 20 x &dollar;0.50 = &dollar;10
&ensp;&ensp;Maximum 'Buy-In' (200 bb) = 200 x &dollar;0.50 = &dollar;100
endif
