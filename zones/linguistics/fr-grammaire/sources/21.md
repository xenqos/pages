# Relatif

## Formes simples
|%[r|qui ]||подлежащее, который (кто, что — выполняет действие)
|%[r|que ]||дополнение, которого / которую / которые (кого, что — над чем делают действие)
|%[r|quoi]||что (то, что / о чём / с чем)
|%[r|dont]||которого / о котором / чей / чья (заменяет предлог de)
|%[r|où  ]||где / куда / когда (указывает на место или время)

## Formes complexes

[|

|%[r|lequel  ]|lesquels  |
|%[r|laquelle]|lesquelles|

[!
%[r|lequel] - прямое дополнение с предлогом, антецедент - одушевлёные/неодушевлёные
!]

[!
%[r|à ] + %[r|lequel    ] = %[r|auquel    ]
%[r|à ] + %[r|lesquels  ] = %[r|auxquels  ]
%[r|à ] + %[r|lesquelles] = %[r|auxquelles]
%[r|de] + %[r|lequel    ] = %[r|duquel    ]
%[r|de] + %[r|lesquels  ] = %[r|desquels  ]
%[r|de] + %[r|lesquelles] = %[r|desquelles]
!]
