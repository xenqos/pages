Adjectif

Genre et Nombre

Genre (Род: +e)

Базовое правило

grand grande
américainaméricaine

-e - оставить без изменений

calmecalme
jeunejeune

Изменение окончаний

-er -> -ère cher -> chère
-f -> -ve actif -> active
-eux -> -euse heureux -> heureuse
-el -> -elle naturel -> naturelle
-en -> -enne ancien -> ancienne

Особые формы (перед гласной / немым h)

beau -> bel -> %[rbelle
nouveau -> nouvel -> nouvelle
vieux -> vieil -> %[rvieille
Особая форма (bel, nouvel, vieil) используется вместо мужского рода, если следующее слово начинается с гласной или немого h:
un beau livre -> un bel homme

Nombre (Число: +s)

Базовое правило

grand%[rgrands
verte%[rvertes

-s, -x - оставить без изменений

gros gros
vieuxvieux

-au, -eau - добавить -x

beau beaux
nouveaunouveaux

-al изменить на -aux

général généraux
nationalnationaux

Исключения на -al (добавить -s)

banal banals
fatal fatals
naval navals
festivalfestivals

Порядок в предложении

Большинство прилагательных идут ПОСЛЕ существительного:
une table ronde, un livre intéressant

Короткие и частые идут ПЕРЕД существительным:
beau, jeune, vieux, bon, mauvais, grand, petit, gros, long
